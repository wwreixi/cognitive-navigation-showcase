# 易用学 · 理论框架简介

## 核心公式

**S = T - C - D**

| 符号 | 含义 | 范围 |
|------|------|------|
| S | 系统健康度 | 0 ~ 1 |
| T | 转化力 | 0 ~ 1 |
| C | 约束力 | 0 ~ 1 |
| D | 内部消耗 | 0 ~ 1 |

---

## 六律演化模型

| 规律 | 含义 |
|------|------|
| 一体两面与对立互根 | 系统状态至少有两个不可约维度 |
| 静态平衡 | 持续上升或下降的平衡 |
| 动态平衡 | 主动适应变量的调节平衡 |
| 盈消虚长 | 过度发展触发约束力回调 |
| 周期迭代 | 持续良性动态演化 |
| 过度消亡 | 系统解体，转化约束力跃迁 |

---

## 警戒区定义

| 区 | S 范围 | 导航指令 |
|----|--------|----------|
| GREEN | ≥ 0.70 | CONTINUE |
| YELLOW | 0.30 ~ 0.70 | RESET_CONTEXT |
| ORANGE | 0.15 ~ 0.30 | NARROW_SCOPE |
| RED | < 0.15 | REQUEST_HUMAN_APPROVAL |

---

## 本案例验证结论

- S = T - C - D 在 15 个测试用例中 **100% 吻合**
- 三 Agent 诊断数据 **完全一致**（0.65/0.95/0.20/0.10/YELLOW）
- 健康度 S 从 0.40 提升至 0.47，**+17.5%**
